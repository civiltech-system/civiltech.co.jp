CivilTech 法人ホームページのソースコードです。

---

## 概要

製造業の現場知識とソフトウェア技術を活かし、実用的なWebサービスを開発する開発組織 CivilTech の公式サイトです。

---

## 技術構成

| 項目 | 内容 |
|------|------|
| HTML | 静的 HTML |
| CSS | TailwindCSS (CDN) |
| JavaScript | Vue 3 (CDN) |
| フォーム | Formspree |
| Web サーバー | Nginx (CloudPanel) |
| SSL | Let's Encrypt |
